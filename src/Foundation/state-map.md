## Cross-Domain Dependencies

Notes for `SK.01.CoreObservabilityFixes` (WO-087 / P-584) and `SK.01.CoreConformance` (WO-087 / P-600); nothing here is a task of this domain.

- **All packages referencing `SharedKernel.Execution` (P-584):** inherit `SharedKernel.Core` transitively (new `.nuspec` dependency, no code change); `docs/packages.md` and `docs/dependency-graph.md` are regenerated by this phase's implementer.
- **14.Presentation (P-584):** add test cases (WebApi `ExceptionHandlingPipelineTests`, gRPC `GrpcExceptionInterceptor` tests, SignalR `ErrorMappingTests`) proving `CommitOutcomeUnknownException` maps to 504 / `DeadlineExceeded`, `TransactionRolledBackException` and `FeatureFlagValidationException` to 500 / `Internal`, with codes `execution.commit_outcome_unknown`, `execution.transaction_rolled_back`, `feature_management.invalid_flag_configuration`. The edges' type switch needs no change. 01 cannot host these tests without a Foundation test depending on Host packages. P-584's "(tested)" bullet is therefore met in 01 only for the mapper inputs; `arch-lead` should attach the status assertions to 14's Phase 1 entry.
- **06.Persistence and its `.Testing` (P-584):** `UnitOfWorkCoordinator` and `FakeUnitOfWork` keep compiling (the parameterless and `(Exception)` ctors stay); their docs that call the rolled-back case an `InvalidOperationException` should be corrected, and any `catch (InvalidOperationException)` for it must move to `TransactionRolledBackException`.
- **05.Application (P-584):** `Application.Pipeline` README/remarks that describe these exceptions follow the new base type and codes; no behavior change.
- **11.Communication (P-584/P-600):** the reverse HTTP/gRPC map reads `unexpected.default` instead of `unexpected.exception`; retry policies may retry a 504 from a commit-unknown response, which the idempotency key must cover.
- **14.Presentation, 11.Communication, consumer services (P-600):** `ErrorCodes.Unexpected.Default` is now `unexpected.default` (`ErrorPresentation`, WebApi README row for the 500 case, SignalR/gRPC factories and their tests, translation catalogs keyed by the old code); `ErrorCodes.Domain.RuleViolated` is now `domain.rule_violated` (`03.Domain` should use the constant everywhere; verify no literal).
- **Implementers of `IDataSubjectRequestHandler` (P-600):** `DataPrivacyErrorCodes.TemporarilyUnavailable` is replaced by `Unavailable = "data_privacy.unavailable"`, returned as `Error.Unavailable`.
- **00.Governance (P-583/P-618):** the sub-block integrity assertion must read the ownership table in this domain's `CLAUDE.md` (adapters share their base package's slot, offsets 50-99), not assume one slot per package; the FluentValidation pass-through mapping removes PascalCase codes the error-code format check would flag.
- **arch-lead (root `CLAUDE.md` L1):** "each package owns one 100-wide sub-block" cannot hold for 01.Core (13 packages, 10 slots in 1000-1999); the root text should allow adapters to share their base package's sub-block.
