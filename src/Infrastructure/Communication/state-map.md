### SK.11.TokenUnavailableEdge — Make AccessTokenUnavailableException map at the edge `○`

**Work order:** WO-087 / P-592 · **Depends on:** SK.01.ObservabilityHelpers (P-580: `IHasError`, implemented by `SharedKernelException`; only T-01's `IHasError` assertion needs it, everything else can start now)

`AccessTokenUnavailableException` carries an `Error` but derives `HttpRequestException`, so a typed client used through its raw `HttpClient` (not the `Result` verbs) lets it escape to an inbound edge, where `SharedKernelExceptionHandler`, the gRPC server interceptor and the SignalR hub filter match only `SharedKernelException` and answer 500 instead of 503. The phase rebases the exception on `SharedKernelException` (Foundation `SharedKernel.Core`, a legal Adapter reference), keeps today's resilience behaviour explicitly instead of by accident of the old base type, and removes every URL, host, OAuth client id and remote free-text value from the token path's logs and `Error`s. Breaking, pre-GA, release-noted: the exception is no longer an `HttpRequestException`; no wire code changes in this phase.

Audit of the outbound token path (evidence, not tasks): `CommunicationLog` events 11000-11002 log `{TokenEndpoint}` (a URL) and `{ClientId}`; `ClientCredentialsTokenClient` puts the server's `error` string (remote free text) into both a log and `Error.Message`; `ClientAuthenticationHandler` forwards an `IAccessTokenProvider`'s `Error.Message` unchanged into the `Error` (a consumer-supplied string that may hold a host) and the exception message embeds it again. `HttpFailure`/`GrpcResultExtensions` messages carry only the `HttpRequestError` enum or fixed text (clean). No other host or URL reaches a log or an `Error` in the base, Rest or Grpc packages.

### SK.11.CommunicationConformance — Conform Communication to the observability gold standard `○`

**Work order:** WO-087 / P-609 · **Depends on:** SK.01.ObservabilityHelpers (P-580), SK.16.TelemetryCapture (P-581), SK.00.ObservabilityReportOnly (P-583), SK.11.TokenUnavailableEdge (P-592). Also reads: SK.13.WildcardTelemetry (P-582, no code change here), SK.01.CoreConformance (P-600, `unexpected.default`), SK.01.CoreObservabilityFixes (P-584, `execution.commit_outcome_unknown`)

Applies root "Observability, exceptions and error codes" (L1-L8, T1-T8, E1-E4, C1-C3) to the three packages. Measured state: 6 bare `EventId` literals (events 11000-11004 and the gRPC interceptor's 11100; the repo-wide "19" of the audit spans all domains), one hand-typed logger category (`"SharedKernel.Communication.Authentication"`), no log class for the interceptor, Rest logs nothing (its propagation handler swallows a failure silently, and an unreadable ProblemDetails or success body is swallowed silently with the exception lost), `ProblemDetailsDeserializer` swallows even the caller's cancellation, three error codes defined as raw literals outside `CommunicationErrorCodes` (`money.proto.invalid`, the 17 `grpc.{status}` names, `http.{status}`), two copies of the same `ErrorType` -> `Error` switch, a money message that embeds amounts, an unreachable `_` authentication arm that reports `access_token_unavailable`, and a missing-provider check that fails at request time instead of at startup. No `ActivitySource`, `Meter` or span exists in this domain and none is added (D-05).

**Breaking, wire-visible, pre-GA, no aliases (WO-087 decision 2):** `communication.unreachable` -> `communication.unavailable` (`CommunicationErrorCodes.Unreachable` -> `Unavailable`, C3, matching the other domains' `*.unreachable` -> `*.unavailable`); `money.proto.invalid` -> `communication.grpc.invalid_money` (`CommunicationErrorCodes.GrpcInvalidMoney`); the logger category of the authentication handler changes from `SharedKernel.Communication.Authentication` to its type name (log filters); the money error message loses the amounts. **Unchanged on purpose:** `grpc.{status}` and `http.{status}` values (hand-kept mirror of 14.Presentation's `GrpcErrorCodes.ForStatus` and framework-problem codes; renaming here alone would break the mirror) move into `CommunicationErrorCodes` as documented constants without changing a character; every other `communication.*` code; all EventIds (no renumbering).
