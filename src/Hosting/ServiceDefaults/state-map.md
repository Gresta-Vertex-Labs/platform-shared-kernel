## Open Work

### SK.13.ServiceDefaultsConformance — Conform ServiceDefaults to the observability gold standard `○`

**Work order:** WO-087 / P-611 · **Depends on:** SK.13.HostObservabilityFixes (P-594), SK.13.WildcardTelemetry (P-582), SK.01.ObservabilityHelpers (P-580: `LoggingEventIdRanges.IsInSubBlock`), SK.16.TelemetryCapture (P-581: log-convention assertions), SK.00.ObservabilityReportOnly (P-583: the zero-findings acceptance)

Applies every applicable rule of root `CLAUDE.md` "Observability, exceptions and error codes" to the seven ServiceDefaults packages. **Applicability, verified on disk:** this domain has no `ActivitySource`, `Meter`, instrument, span, `Error` or classified exception (a search of the production code for `new ActivitySource`, `new Meter`, `SetTag`, `Error.X(`, `SharedKernelException` finds none), so **T1, T3, T5, T6 and E1, E4, C1-C3 do not apply and no task is planned for them**; T2 shipped in `SK.13.WildcardTelemetry`, T7/T8 in `SK.13.HostObservabilityFixes`. Applicable: **L1-L8, T4 (tag keys from constants), E2, E3**. Decision recorded in `## Decisions`: the request-context and tenant middleware **tag** the ambient server span and start no span of their own (a per-request span in the hottest path with no failure semantic of its own is not warranted, and T1 would then require a `SharedKernel.MultiTenancy` source name for no reader).

**EventId layout (L1).** The family does not exceed its slots here: seven packages fit ten sub-blocks of the 13000-13999 block, so no package-family sharing or offsets are needed (unlike `01.Core`, 13 packages in 10 slots). `SharedKernel.MultiTenancy` keeps 13100-13199 untouched. The other packages move from the shared 13000-13099 range to their own sub-block, renumbered **once**, in the release that carries both phases. `LoggingEventIdRanges.ServiceDefaults` (13000) is the domain base; the Security domain's mTLS package owns 12300-12399 (`SK.12.SecurityConformance`), which is a different domain's block with a coincidentally similar index: tests must name the domain base explicitly and never compare sub-block indexes alone.
