SK.03.Design tasks D-15..D-18 were added by domain-arch-planner in the WO-009 audit but the designs were already written into 03.Domain/CLAUDE.md in the same session. When the domain-phase-implementer was asked to complete the Design phase, the correct action was to verify CLAUDE.md contains the designs and mark state-map tasks ● — no code or CLAUDE.md content changes required.

**Why:** The arch-planner wrote both the CLAUDE.md content and the state-map task rows simultaneously; the implementer's job was verification + bookkeeping only.

**How to apply:** For any Design phase task where the arch-planner already updated CLAUDE.md, skip CLAUDE.md edits and only update the state-map. The sync-brain call should append a changelog entry noting "no content edits needed (designs already present)".
