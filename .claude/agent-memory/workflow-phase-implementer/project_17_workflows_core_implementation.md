**Architectural decisions made this session, not previously specified in the locked brain:**
- Two distinct `AsyncLocal`-backed ambient-context bridges were introduced as the sanctioned exception to "no static mutable state": `Interception/ActivityPropagationContext.cs` (worker-side, feeds `ActivityBase.TenantScope`, needed because `ActivityInfo` carries no `Headers`) and `Interception/DispatchPropagationContext.cs` (client-side, feeds the interceptor's header-writing, needed because no dispatch-surface SDK type carries a `TenantScope` parameter). Both are per-logical-call-context, isolated per async flow — not cross-request shared state.
- `WorkflowFailureMapper.ToFailure(Error)` stashes `(int)error.Type` as the `ApplicationFailureException`'s first structured `details` element, so `.ToError`'s inverse can recover the original `ErrorType` (not just `Error.Code`) — a stronger round trip than the original design called for.
- `WorkflowIdFactory`/`WorkflowDispatcher`/`GetHandle` all throw `ArgumentException` synchronously for invalid input (null business key, `TenantScope.None`) rather than returning `Result` — matches the interface contract's literal signature (`GetHandle` returns bare `IWorkflowHandle`, not `Result<IWorkflowHandle>`), while `StartAsync`'s fail-closed tenant guard returns `Result.Failure(WorkflowErrors.TenantScopeMissing())` before touching the client (Result-returning surface).
- `ITemporalWorkflowsBuilder.WithWorker`'s `tune` parameter is `Func<WorkerTuningOptions, WorkerTuningOptions>`, not `Action<WorkerTuningOptions>` as the brain's interface-contract prose literally said — the brain's own usage example (`tune => tune with { MaxConcurrentActivities = 50 }`) only compiles as a `Func`, since a `with`-expression can't be a valid `Action`-delegate statement body. Corrected in the implementation; brain prose not yet corrected (flag if revisiting Hosting).
- A small internal `TemporalWorkflowsCompositionLogger : IHostedService` (Hosting/) logs the "worker built" summary at `StartAsync`, since `Build()` itself runs before any `IServiceProvider` exists and has no `ILogger` available. Registered ONLY on the worker-hosting path — never on `.AsClientOnly()`, preserving the hard "no `IHostedService`" rule for client-only compositions.
- `WorkflowErrors`' 15 factories were assigned `ErrorType`s not explicitly specified by the brain (only `AlreadyStarted`=Conflict, `TenantScopeMissing`=Unauthorized, `DeterminismViolation`=Unexpected were spelled out): `NotFound`=NotFound; `Cancelled`/`Terminated`/`TimedOut`/`QueryFailed`/`SignalFailed`/`ServiceUnavailable`/`NamespaceNotFound`/`WorkerNotConfigured`/`PayloadCodecFailure`=Unexpected; `InvalidWorkflowId`/`InvalidWorkflowRegistration`=Validation.
